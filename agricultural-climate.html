Climate Shocks & Agricultural Prices in Türkiye

Role Solo researcher
Period 2014–2024 panel data
Tools Python · Open-Meteo API · TÜİK · Gradient Boosting · Panel FE
Status Ongoing — feeding into MA thesis

Overview

This project tests whether frost events causally affect producer prices across Turkish agricultural markets, using a hybrid ML + econometrics pipeline. The central design challenge was that standard aggregate models mask enormous heterogeneity across crops — a frost event that destroys tomato yields has a completely different price transmission mechanism than one hitting dormant apple orchards in winter.

The analysis uses province-level panel data covering 81 Turkish provinces built via a custom Python pipeline querying Open-Meteo ERA5-Land reanalysis climate data and official farm gate price series from TÜİK (Turkish Statistical Institute). Prices are deflated to real values using CPI (base Jan 2024) to strip out the inflationary environment.

Data & Methods

Dependent variable: Monthly average farm gate prices (TÜİK) across nine crops, deflated to real values (CPI 2003=100, base Jan 2024).

Crop clusters — theoretically motivated groupings:

  • Perishable vegetables — tomato, pepper, eggplant (high frost sensitivity, fast price transmission)
  • Storable fruits — apple, pear (buffered by cold storage; slower transmission)
  • Biological controls — spinach (cold-hardy baseline), citrus, cherry, apricot (dormancy dynamics)

Climate features: frost day frequencies at −0°C to −5°C thresholds, False Spring dummy, precipitation totals, maximum wind speed, humidity — all at monthly resolution per province.

Three-stage pipeline:

  • Stage 1 — Binning analysis: test the linearity assumption across discrete frost intensity ranges before committing to a single threshold
  • Stage 2 — Gradient Boosting Regressor: identify the biological tipping point (Tcrit) via Partial Dependence Plots; the ML-derived threshold is −0.93°C for the sensitive cluster
  • Stage 3 — Two-Way Fixed Effects panel model: distributed lag structure at t, t−1, t−2, t−3 with city and time fixed effects to absorb unobserved province-level heterogeneity and common macro shocks

Key Findings

+6.53%

Price increase at Lag 1 in the sensitive cluster (perishables + citrus), p<0.001

+4.85%

Additional effect at Lag 2, p<0.01 — confirms delayed supply disruption channel

23–47%

Price shock range for perishable vegetables (tomato, pepper, eggplant) within 2 months

0%

Effect on dormant stone fruits (cherry, apricot) — biological null confirms model validity

76.6%

Share of production concentrated in coastal "Safe Havens" (Antalya region) — geography stabilizes national markets

The aggregate model tells a misleading story: applying a single fixed-effects specification across all crops yields only marginal significance at Lag 3 (~1%, p=0.034). The signal appears only when crops are stratified by their physiological frost-response mechanisms — a reminder that theoretical priors should drive grouping decisions, not convenience.
