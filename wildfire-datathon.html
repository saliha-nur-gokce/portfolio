The Hidden Geography of Wildfire Displacement

Team Saliha Nur Gökçe, Ahsen Neva Atik, Yunus Emre Gündoğmuş
My Role Data integration, regression analysis, PCA + clustering design, presentation
Coverage 1,648 events · 87 countries · 2019–2024
Tools Python · NASA FIRMS API · Plotly Dash · AWS EC2

Overview

Multi-source event-level analysis of 1,648 wildfire displacement events across 87 countries (2019–2024). The central question: does fire intensity — measured via NASA FIRMS Fire Radiative Power (FRP) — predict who gets displaced? The answer: barely. Fire size explains roughly 10% of displacement variance globally.

The more telling finding is what happens when you disaggregate by income group. The FRP–displacement correlation inverts in low-income countries (ρ = −0.31), meaning larger fires are associated with fewer reported displacements there. This is not a damage signal — it is a reporting-capacity signal. Countries with weaker displacement monitoring systems systematically under-report events regardless of fire severity.

Normalized wildfire displacement — country-level overview (2019–2024)

Data Sources

  • IDMC GIDD — wildfire displacement events (displacement counts, dates, coordinates)
  • NASA FIRMS API — Fire Radiative Power (FRP) and hotspot counts, fetched via FIRMS area API, matched to each IDMC event by a ±5-day date window and geocoded bounding box
  • ND-GAIN Country Index — adaptive capacity and vulnerability scores per country
  • World Bank — GDP per capita, population
  • EM-DAT (CRED) — economic damage (available for 35 of 87 countries)

Methods

  • Event-level integration: geocoded IDMC records joined to FIRMS API output using a spatial bounding box and temporal window; enriched with ND-GAIN and World Bank country-level indicators
  • Correlation analysis: Spearman and Pearson correlations computed globally and stratified by World Bank income group to test whether the FRP–displacement relationship is stable
  • Log-log OLS with fixed effects: country and year FEs, R² = 0.17 — confirms that structural country characteristics absorb most displacement variance, not fire intensity itself
  • PCA: 6 variables compressed to two principal components — PC1 captures wildfire exposure (44% of variance), PC2 captures adaptive capacity (32%)
  • K-Means clustering (K=4, silhouette=0.277): identifies country risk profiles from the PCA space
  • Composite risk scoring: original ND-GAIN vulnerability weights revised to down-weight the reporting-biased FRP signal in low-income contexts
